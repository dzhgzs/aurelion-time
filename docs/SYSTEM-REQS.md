# 操作系统与运行环境说明书

本文档详细说明 AURELION 时光在各操作系统上的支持范围、运行需求、数据存储位置与故障排查方法。

## 1. 操作系统支持矩阵

| 操作系统 | 最低版本 | 架构 | 形态 | 状态 |
|---|---|---|---|---|
| Windows 10 | 1809（2018 年 10 月更新） | x64 | 安装版 / 便携版 / 绿色版 | ✅ 完整支持 |
| Windows 11 | 全部版本 | x64 | 安装版 / 便携版 / 绿色版 | ✅ 完整支持 |
| macOS | 10.15 Catalina+ | Intel (x64) + Apple Silicon (arm64) | zip 通用包 | ✅ 完整支持（托盘与开机自启行为略有差异） |
| Linux | — | — | — | ⚠️ 未官方打包；开发者可自行 `npm start` 运行（托盘/自启需自行验证） |
| 浏览器模式 | Chrome / Edge 等现代 Chromium 浏览器 | — | 双击 `index.html` | ✅ 界面与计时完整；无托盘常驻、无开机自启、无系统通知增强 |

> 运行时内核：Electron 33（Chromium 130 / Node.js 20）+ three.js r152。Electron 33 官方支持 Win10 1809+ 与 macOS 10.15+，本应用与之一致。

## 2. 硬件与图形需求

- **GPU**：任何支持 WebGL 的显卡均可。检测到无独立 GPU 的软件渲染环境（SwiftShader/llvmpipe）时，应用会自动降载——关闭阴影/尘埃/毛玻璃并锁定 1 倍渲染缓冲，保证不卡死。
- **性能自适应**：默认关闭；在外观面板手动开启后，帧率过低时自动逐级降低渲染精度，且任何降档都不会放大渲染缓冲。
- **内存 / 磁盘**：建议空闲内存 ≥ 300MB；安装版需约 250MB 磁盘空间，绿色版解压后同体积，便携版每次启动需临时解压空间约 250MB。
- **显示器**：1360×860 以上体验最佳；窄窗（≤860px）自动切换自适应布局；支持刘海屏安全区。

## 4. 数据存储位置

| 数据 | 位置 |
|---|---|
| 全部配置镜像（闹钟/倒计时/偏好，原子落盘） | `%APPDATA%\AURELION 时光\aurelion-config.json` |
| 每周自动快照 | 同目录 `aurelion-backup-YYYYMMDD.json`（保留最近 4 份） |
| 窗口大小/位置记忆 | 同目录 `window-bounds.json` |
| 故障诊断日志（**打包版**） | 同目录 `crash.log` |
| 故障诊断日志（开发版/源码运行） | 项目根目录 `crash.log` |
| 手动备份导出 | 用户自选位置（JSON，含全部 `aurelion.*` 键） |

> 三种启动形态（安装/便携/开发）**共享同一份数据目录**，换用另一形态配置不丢；「导出/导入」可跨电脑迁移。macOS 的对应目录为 `~/Library/Application Support/AURELION 时光/`。

## 5. 已知限制（诚实清单）

1. **闹钟不能唤醒睡眠中的电脑**——系统级限制（Electron 无法申请唤醒调度）。建议配合「屏幕常亮」或在系统电源设置中允许唤醒定时器。
2. **便携版首次启动 3~30 秒**：单文件自解压 + 安全软件逐文件扫描是固有机制，日常使用推荐安装版或绿色版。
3. **2027 年后法定假日表**：未收录年份按法定基准日自动兜底（界面标注「暂按法定假日，未含调休」），国务院通知公布后编辑 `js/lunar.js` 的 `VACATIONS` 表即可精确化。
4. **语音报时**：使用系统语音合成（Windows 中文语音包），不同系统音色与语速有差异。
5. **浏览器模式**：受浏览器限制无托盘/自启/任务栏闪烁；部分浏览器在后台标签页会节流定时器，长时间挂机建议使用桌面版。

## 6. 故障排查

| 现象 | 排查步骤 |
|---|---|
| 启动黑屏 / 3D 不渲染 | 查看日志中是否连续 GPU 崩溃；应用已自动生成 `.no-gpu` 并以软件渲染重启；可手动删除 `%APPDATA%\AURELION 时光` 旁的 `.no-gpu` 重试 |
| 启动缓慢 | 首次启动含安全软件扫描开销；便携版换绿色版/安装版；多实例会争抢缓存——应用有单实例锁保护 |
| 设置丢失 | 配置双写（本机存储 + 文件镜像）+ 每周快照，丢失会被自动恢复；若手动清理过系统缓存，重启应用即从镜像回填 |
| 闹钟不响 | 检查闹钟开关与星期设置 → 托盘 tooltip「下次提醒」→ 系统音量/静音 → 夜间免打扰仅静音非闹钟提醒 |
| 上报问题 | 附上 `crash.log` 相关片段 + 应用版本 + 操作系统版本（模板见 Issue 表单） |

## 7. 卸载

- 安装版：系统「应用与功能」卸载；数据目录保留，可手动删除 `%APPDATA%\AURELION 时光`。
- 便携版/绿色版：直接删除文件；同上清理数据目录即可。
